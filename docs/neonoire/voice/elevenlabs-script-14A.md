## Formatting rules (this film's house style)

- **One line = one take.** Generate each row separately; never merge two speakers or two rows.
- **Tags go in square brackets, right before the words they colour:** `[dryly]`, `[evenly]`, `[gently]`, `[quietly]`, `[curious]`, `[weakly]`, `[tired]`, `[urgently]`, `[desperately]`. One tag per line is usually enough; a tag holds until the next one.
- **No whispers.** Never `[whispers]`; use `[quietly]` instead. Plain, untagged lines sound like a narrator, so every line carries a short direction tag.
- **Pauses inside a line:** `[short pause]` (a breath) or `[pause]` (the script's *(beat)*). An em-dash `—` is a cut-off or an interruption. Ellipses `…` give a longer, thinking pause. Use them sparingly.
- **Emphasis:** capitalise one word at most, only if the moment needs it. None of these lines do.
- **No stage directions** in brackets (`[grinning]`, `[pacing]`): they are not performed.
- **Spoken text stays exactly the script's** (the subtitle). Never rewrite a line to make a tag work.
- **Emotion tags available** (full list): excited, happy, sad, angry, nervous, curious, sarcastic, surprised, tired, warmly · delivery: whispers *(not used here)*, shouting, softly, dramatically, mischievously, cautiously, slowly · voice quality: deep voice, high voice, raspy, breathless, trembling voice · non-verbal: laughs, chuckles, sighs, exhales, gasps, clears throat, crying · pauses: short pause, pause, long pause · timing: interrupting, jumping in, overlapping.

## After generating

1. Download each take as `L01.mp3` … `L36.mp3` into one folder (links expire after two hours).
2. `FFMPEG=/path/to/ffmpeg node scripts/neonoire/voice-batch.mjs --plan docs/neonoire/voice/elevenlabs-plan-14A.json --dir <folder> --dry` checks the files and the plan; drop `--dry` to ingest and lay the gaps out.
3. `npm run build:neonoire && npm run verify:neonoire`, then listen with `node scripts/neonoire/animatic.mjs --scene 14A --resolution 480 --preset ultrafast`.
4. If a take is wrong, regenerate that one row only and re-ingest with `--replace` (see `voice/README.md`); the old take is archived, never deleted.

Frames 336/337/339/342/343 are the current picture assignments; if you move a line to another shot, change `frame` in the plan JSON before ingesting.
